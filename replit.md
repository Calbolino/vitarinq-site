# Vitarinq Landing Page

A static landing page for Vitarinq (a premium smart ring product). Built with plain HTML and CSS.

## Project Structure
- `index.html` — main landing page (French, with English i18n attributes)
- `styles.css` — site styles
- `assets/` — product images
- `server.js` — minimal Node.js static file server for development (serves project root on port 5000)

## Running locally
The workflow `Start application` runs `node server.js`, serving the site on port 5000.

## Deployment
Configured as a static deployment serving the project root. Publish via Replit's Publish button.
